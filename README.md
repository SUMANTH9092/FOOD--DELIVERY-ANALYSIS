# 🍔 Food Delivery Analysis

## 📌 Project Description

The **Food Delivery Analysis System** is a data-driven project that analyzes and compares food items across multiple online delivery platforms such as Zomato, Swiggy, Deliveroo, and Blinkit. The system helps users identify the **best value food option** based on various parameters including price, customer rating, delivery time, quantity, and quality.

The application allows users to input a food item (e.g., Biryani, Pizza, Dosa) and generates a detailed analysis of available options from different platforms. It evaluates each option using a calculated **overall score**, which helps in selecting the most optimal choice.

## 🔍 Key Functionalities

* Accepts user input for any food item
* Displays the **best overall value option**
* Compares multiple platforms and restaurants
* Generates a ranked list of top 30 food options
* Uses multiple parameters:

  * 💰 Price
  * ⭐ Rating
  * ⏱️ Delivery Time
  * 🍱 Quantity
  * 🏆 Quality

## 📊 Output Explanation

### ✅ Best Overall Result

The system identifies the best option based on combined metrics.
Example (Biryani):

* Platform: Zomato
* Restaurant: Chutneys
* Price: ₹163.85
* Rating: 4.7/5
* Delivery Time: 36 mins
* Overall Score: **0.83**

---

### 📋 Ranked Food Options

* Displays **Top 30 results**
* Sorted by **overall score (highest first)**
* Includes detailed comparison table:

  * Platform
  * Restaurant
  * Food Item
  * Price
  * Rating
  * Delivery Time
  * Quantity & Quality indicators
  * Final Score

---

### 📈 Data Visualization

The system generates graphical insights for better understanding:

* 📊 **Average Price Comparison** across platforms
* ⭐ **Average Customer Ratings**

These visualizations help users quickly identify:

* Cheapest platform
